# delivery-form

Мини-приложение - форма оформления заявки на доставку посылки, разбитая на 3 шага. После отправки - страница с историей заявок.

---

## 🎯 Цель проекта

Показать умение:

- Проектирования интерфейсов с многошаговыми формами
- Работы с состоянием приложения и сохранением данных
- Типизации приложения с использованием TypeScript
- Реализации валидации пользовательского ввода
- Построения адаптивного интерфейса без UI-библиотек
- Организации кода и соблюдения инженерных стандартов разработки

---

## ⚙️ Ключевые возможности

Многошаговая форма оформления заявки на доставку (3 шага)

- Сохранение введённых данных между шагами
- Прогресс-бар / степпер для отображения текущего шага
- Валидация пользовательских данных
- Сводка введённых данных перед отправкой заявки
- Сохранение заявок в localStorage
- Страница истории оформленных заявок
- Поиск заявок по имени получателя и городу назначения
- Фильтрация заявок по типу груза
- Просмотр полной информации о заявке
- Удаление заявки с подтверждением через кастомный диалог
- Адаптивная верстка для мобильных устройств и десктопа

---

## 🧱 Архитектура

Проект построен по методологии Feature-Sliced Design:

- Изолировать бизнес-логику
- Делать код масштабируемым
- Упрощать поддержку и расширение проекта

Архитектура разделяет:

- сущности (entities),
- пользовательские сценарии (features),
- переиспользуемые модули (shared).
